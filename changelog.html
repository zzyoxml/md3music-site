v6.4.1

v6.4.0

上一版本 2026-11-15 · 构建于 06:11 UTC

歌词渲染全面优化，新增多项歌词外观与动画设置，并完善车机、TV、云盘与 Windows 桌面体验。

新增功能

  • 新增歌词字体柔边抗锯齿、清晰度与模糊渐变效果，改善歌词显示质量。
  • 新增歌词提前换行、预启动提前量、错峰参数、已播 / 未播透明度及副行显示范围设置。
  • 新增歌词动画预设管理与“流畅优先”/“性能优先”预设，统一 Android 与 Windows 平台默认配置。
  • 新增在线歌词头部信息块过滤规则，统一歌词作者与元信息判定。
  • 新增小米 CarWith 车机互联，支持主题跟随与投屏歌词，并增加下电日志取证。
  • 新增本地音乐按指定文件夹扫描，并修复文件夹扫描与排除菜单的 TV 遥控焦点问题。
  • 新增 USB 独占输出入口，支持长按歌曲信息复制完整歌曲资料。

体验优化

  • 歌词渲染全面优化，降低 CPU 占用、内存峰值与切歌时的位图开销，提升滚动和动画流畅度。
  • 重构歌词错峰、预启动、级联与间奏动画逻辑，修复卡顿、跳位、回退、速度突变和预启动失效问题。
  • 车机切歌流程优化，修复歌词与声音不同步、旧歌词残留及歌曲切换延迟问题。
  • 音频共存模式退出焦点体系，避免切歌抢占其他应用的音频焦点。
  • 扩展划掉应用即停止播放能力，修复小米及部分 Android 设备后台停止延迟。
  • 优化 Android 发版包体积，压缩原生库、资源和图标，下载体积显著减少。
  • TV 端优化搜索框、目录选择和弹层焦点导航，修复首焦点与焦点逃逸问题。
  • TV 端支持在歌曲列表按 OK 键直接打开播放页，恢复歌曲弹幕开关并隐藏设置搜索框。
  • 优化大屏布局自适应限宽比例，壁纸模式下顶栏标签透明显示背景。
  • 云盘歌曲接入在线歌曲信息匹配，完善播放、歌单和专辑信息处理。
  • 本地音乐与歌单排序统一改为按拼音 A→Z。
  • 搜索历史支持长按删除单条记录，清空历史增加二次确认。
  • Windows Zen、窗口拖拽与 DWM 动画优化，消除最大化过渡残影和中间帧闪烁。

问题修复

  • 修复歌词辉光换行位移、英文字距异常、颜色不一致、间奏圆点位置和头部信息显示问题。
  • TV 部分旧设备没有 SAF 导致闪退的问题，内置 App 文件管理器兜底。
  • 修复 MCP 按哈希播放歌曲不匹配、歌单写入、专辑名缺失及控制命令挂起问题。
  • 修复排行榜缓存串榜、过期响应覆盖及旧榜单歌曲显示错误。
  • 修复账号切换重复点击、嵌套导航误弹路由及详情分页加载截断问题。
  • 修复 Windows 播控中心封面闪烁、窗口图标更新、滚轮刷新及版本更新提示问题。
  • 隐藏非 Android 平台的硬件解码设置，修复硬解探测、退出尾音和诊断日志崩溃问题。
  • 修复 DLNA 投屏 controlURL 解析，支持乐播投屏、Vivo 播放会话衔接及三星等设备后台退出问题。
  • 修复 TV 部分用户协议页默认勾选与确认按钮无法聚焦的问题。
